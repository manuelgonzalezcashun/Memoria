Maria Lite by Kreativ Font
------------------------------------
Maria Lite is a free slab, sans-serif handwriting type that can be used to give you a pen like writing style for your designs. 

It contains only the Basic Latin glyphs. If you need more glyphs please check out Maria http://www.kreativfont.com/maria.

It is also my third designed typeface, so please let me know if you find bugs OR what other improvements do you need ;)

Kreativ Font 2013 - http://www.kreativfont.com. Feel free to use it in any personal OR commercial work.
